Feature Overview

Tudo que você precisa para mestrar e jogar

Do parser de linguagem natural ao motor de combate D&D 5e, passando por persistência híbrida e narrador IA — cada peça foi pensada para desaparecer e deixar só a história.

🎮

Interface Desktop Nativa

CustomTkinter com tema dark-fantasy responsivo. Painéis redimensionáveis: imagem atmosférica no topo, Diário de Bordo com scroll, Caminhos e Ações em botões adaptativos, entrada de comando livre com placeholder contextual.

CustomTkinter Responsive Layout Dark Theme
⚔️

Motor de Combate D&D 5e

Implementação fiel: rolagem d20 com vantagem/desvantagem, CA calculada (armadura + DEX + escudo), tipos de dano (cortante/perfurante/contundente/elemental), resistências/vulnerabilidades/imunidades, crítico (nat 20 = dano dobrado), salvaguardas de morte.

D&D 5e Rules Advantage/Disadvantage Damage Types
🤖

Narrador IA (OpenAI) + Fallback Local

Thread assíncrona chama gpt-4o-mini para interpretar intenção (COMBATE, NAVEGAR, INTERACAO, MAGIA, MANOBRA, DESCANSAR, OUTRO) e narrar o resultado. Se a API falha, narrador local com templates atmosféricos assume transparente.

OpenAI API Async Thread Graceful Fallback
🗣️

Parser Local de Linguagem Natural

Entende comandos livres antes de ir pra IA: "vou pro norte", "examino o pedestal", "falo com o taverneiro", "abro o baú", "pego a espada", "ajudar o gnomo". Regex portátil, zero latência, offline-first.

Regex Parser Zero Latency PT-BR
💾

Persistência Híbrida (Local + PostgreSQL)

SQLAlchemy async com asyncpg. Salva local (JSON em saves/) e no PostgreSQL remoto. Sincronização automática: cria personagem, atualiza HP/XP/inventário, salva estado de salas, party ID compartilhado. Reconexão resiliente.

SQLAlchemy asyncpg JSON + SQL
🗺️

Mundo Carregado do Banco (159 salas)

Export JSONs do PostgreSQL → db_export/: aventura_cidadela.json (cenas com conexões, hazards, loot, NPCs), bestiario_cidadela.json (43 monstros com stats completos), aliados_e_npcs.json (12 NPCs com diálogos), campanhas.json, aventuras.json. Load instantâneo em memória.

159 Salas 43 Monstros 12 NPCs
💬

Sistema de Diálogo com NPCs

NPCs por sala (localização exata + fallback por keywords + genérico para Carvalhal). Opções de diálogo como botões de ação: Pedir bebida (cura +2 HP, 2 PO), Perguntar rumores (desbloqueia lore), Alugar quarto (restaura tudo, 5 PO), Comida (1d8+2 HP, 3 PO).

Dialogue Trees Economy Rest Mechanics
🎒

Inventário, Loja & Progressão

Inventário por classe (Guerreiro: Cota de Malha + Espada Longa + Escudo + Besta Leve). Loja da Vila (poções, antídotos). Level up (HP por classe, slots de magia, proficiência). Ouro, XP, Hit Dice, descanso curto/longo.

Class-based Loadout Shop System Level Up
🖼️

Cache de Imagens Inteligente

URLs no imagens_config.py (Imgur/CDN). Download assíncrono com cache em disco (.cache_imagens/) — primeira vez baixa, depois usa arquivo local. Placeholder procedural (Pillow) se falhar. Redimensiona responsivo no resize da janela.

Async Download Disk Cache Pillow Fallback

Fluxo de Comando do Jogador

  1. Digite no chat ou clique botão
  2. Parser Local tenta match (regex)
  3. Se entende → executa mecânica direto
  4. Se não → Thread IA (_interpretar_com_ia)
  5. OpenAI retorna {intencao, alvo, estilo...}
  6. _processar_ia_resultado executa mecânica
  7. Narrador (IA ou local) gera texto
  8. Log atualiza + auto-save

Tech Stack

Ferramentas Escolhidas a Dedo

Python 3.11+ CustomTkinter SQLAlchemy 2.0 asyncpg OpenAI API Pillow cachetools python-dotenv PostgreSQL UV (package mgr) Git Bash / MSYS2

Por que CustomTkinter?

  • Tema dark nativo + customização CSS-like
  • Widgets modernos (CTkButton, CTkTextbox, CTkScrollableFrame)
  • Leve — sem Chromium/Electron overhead
  • Binário nativo Windows via pyinstaller

Por que SQLAlchemy Async?

  • Async/await nativo — não bloqueia UI
  • ORM tipado com Mapped/mapped_column
  • JSONB nativo do PostgreSQL para inventário/estado
  • Migrações via Alembic quando necessário

Por que JSON + SQL Híbrido?

  • UI desktop roda offline (JSON em memória)
  • Bot Telegram usa SQL (persistência real)
  • db_loader.py abstrai a fonte
  • Export/Import via scripts simples
Getting Started

Rode em 3 Passos

1

Clone & Configure

git clone <repo>
cd rpgbot-mezzarpg
cp .env.example .env
# Edite DATABASE_URL e OPENAI_API_KEY
2

Instale Dependências

uv sync
# ou: pip install -r requirements.txt
# pygame: uv pip install pygame
3

Rode o Protótipo

python pygame_ui.py
# Janela abre em ~2s
